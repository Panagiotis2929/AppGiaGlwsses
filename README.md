## Περιγραφή Έργου
Η εφαρμογή **AppGiaGlwsses** αποτελεί ένα ολοκληρωμένο εκπαιδευτικό λογισμικό που αναπτύχθηκε στα πλαίσια του εργαστηριακού έργου για το μάθημα **«Προγραμματισμός Διεπαφών Χρήστη» (User Interface Programming)** κατά το Εαρινό Εξάμηνο 2024–2025.

Κύριος στόχος της εφαρμογής είναι η διευκόλυνση της εκμάθησης βασικών ξένων φράσεων μέσω μιας διαδραστικής και φιλικής προς τον χρήστη διεπαφής (GUI). Ο χρήστης έχει τη δυνατότητα να πλοηγηθεί σε διαφορετικές θεματικές ενότητες, να επιλέξει τη γλώσσα της προτιμήσεώς του και να αξιολογήσει τις γνώσεις του μέσω ενός δυναμικού συστήματος Quiz.

## Κύριες Λειτουργίες
* **Διαδραστική Αρχική Σελίδα:** Επιλογή γλώσσας στόχου και κατηγορίας ενδιαφέροντος.
* **Διαχείριση Περιεχομένου:** Δυναμική προβολή και φιλτράρισμα εκπαιδευτικών φράσεων ανάλογα με τις επιλογές του χρήστη.
* **Σύστημα Αξιολόγησης (Quiz):** Διαδραστικό Quiz πολλαπλής επιλογής για τον έλεγχο προόδου.
* **Πίνακας Αποτελεσμάτων:** Άμεση ανατροφοδότηση (feedback) στον χρήστη με την ολοκλήρωση του Quiz και καταγραφή του σκορ.

## Τεχνολογικό Stack & Απαιτήσεις
Για την υλοποίηση και την εκτέλεση του έργου χρησιμοποιήθηκαν οι ακόλουθες τεχνολογίες:

* **Γλώσσα Προγραμματισμού:** Java 21 (LTS)
* **Πλαίσιο GUI:** JavaFX 21 (με χρήση FXML για τον διαχωρισμό UI και λογικής)
* **Διαχείριση Έργου / Build Tool:** Maven 3.9+
* **Περιβάλλον Ανάπτυξης (IDE):** VS Code / NetBeans
* **Αρχιτεκτονικό Πρότυπο:** MVC (Model-View-Controller)
